# Changelog

## 2.0.0 — 2026-11-23

First public open-source release of the native Windows edition.

- C++/Win32 x64 host with native file dialogs, file streaming, preferences, and PDF writes.
- Bundled PDF.js viewer in WebView2; no .NET runtime requirement.
- Search, page navigation, thumbnails, bookmarks, zoom, rotation, layouts, forms, annotations, and printing.
- Imported image signatures with positioning, resizing, reusable templates, and per-instance inline color and thickness controls.
- Undo/redo and PDF save/reopen coverage for signature edits.
- Password-protected PDFs, invalid-document recovery, recent-file position restore, and Unicode paths.
- Native integration suite with 104 checks, contributor documentation, and Windows build/release workflows.

The native app build was validated locally before publication. Windows builds are unsigned.
